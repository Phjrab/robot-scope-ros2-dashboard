확장 기능

저장 지도 합치기, 장애물 관측, 기록 재생을 한곳에서 확인합니다.

여러 지도 합치기

3D 지도 2개 이상 선택 → 기준 지도 지정 → XY·3D 비교 → 자동 정합 → 겹침률·RMSE·경고 검토 → 후보 수락 → 새 PCD 저장.

필요하면 수동 XY·Yaw 또는 같은 지점의 XYZ 대응점을 입력합니다. 화면은 샘플 미리보기이며 저장에는 원본 전체 점을 사용합니다. 저장 완료 후 사본 목록의 revision·SHA를 확인하세요.

새 PCD는 리뷰용 사본입니다. Nav2에서 사용할 지도 적용은 A1의 별도 검증 절차로 진행합니다.

장애물 3D 관측

검증된 지도·좌표·시각에 연결된 관측을 확인합니다. ADVISORY_ONLY는 관측 정보의 검토 수준입니다. costmap 반영·회피·충돌 보호의 현장 검증 상태는 별도로 확인하세요.

SIMULATED는 합성 자료, UNAVAILABLE은 입력 미연결, STALE은 유효 시간 만료입니다.

콘 표시

관측 화면의 CONES 스위치를 켜면 콘을 표시합니다. 화면을 새로 열 때는 꺼진 상태로 시작합니다. 콘의 실제 3D 위치는 원본 XYZ·교정·지도 연결 근거가 있을 때 확인할 수 있습니다.

주행 기록 재생

로컬 기록 파일을 실행 A에 선택하고, 비교할 파일은 실행 B에 선택하세요. 재생 속도와 타임라인으로 앞뒤 이동하며 목표 결과·정지·ACK·오차를 확인합니다. 표본의 원본 시각은 그대로 보존됩니다.

파일은 이 브라우저에서 읽습니다. 로봇 전송 명령 수는 0입니다. 두 실행의 조건이 다르면 참고 비교로 표시됩니다.

성능 진단 안내

C7은 처리량·단계별 시간·데이터 크기를 확인하는 오프라인 도구입니다.

Jetson 실측
NOT_RUN · 제공된 장비 성능 측정 없음
센서→화면 지연
UNKNOWN · 센서·서버·브라우저 시계 대응 필요

제공된 검증 결과는 2026-11-05의 로컬 합성 입력입니다. 용량 경계 26개 중 18개 전달, 한도 초과 8개 거부를 확인했습니다. 입력·설정·측정 환경과 소스 고정 정보는 검증 기록에서 확인하세요.

오프라인 실행 방법

준비된 개발 환경의 저장소 루트에서 실행합니다. prepare는 C7이 고정한 Git 객체를 로컬에서 읽습니다. 누락된 객체와 의존성은 검증 담당자가 먼저 준비합니다.

python -m robot_dashboard.expansion_diagnostics prepare --repo . --output /tmp/rs-c7-pins
python -m robot_dashboard.expansion_diagnostics run --deps /tmp/rs-c7-pins --profile baseline --output /tmp/rs-c7-baseline.json
python -m robot_dashboard.expansion_diagnostics run --deps /tmp/rs-c7-pins --profile bounded --config-snapshot /tmp/rs-c7-baseline.json --output /tmp/rs-c7-bounded.json

실행 결과에 입력 hash와 측정 구간을 함께 보관합니다. 실제 장비에서의 실행은 A1이 정한 시험창에서 진행합니다.

합성 관측 데모 안내

검증 담당자가 개발 환경에서 별도 데모를 시작하고 표시된 로컬 주소를 엽니다.

python -m experiments.expansion_20261101.cone_display.demo --port 4192

로컬 브라우저에서 http://127.0.0.1:4192/를 열고 콘 표시를 선택합니다. 데모는 SIMULATED · 독립 평면 좌표로 표시합니다. 실제 지도 정렬·높이는 미검증입니다.

활성화와 연결 준비

관리자가 기능을 켜고 준비 상태를 확인합니다. REPLAY는 로컬 파일을 사용하는 독립 기능입니다. 지도·관측은 HTTPS와 검증된 데이터 제공자 연결이 필요합니다.

HTTP로 접속했다면 관리자가 안내한 HTTPS 주소를 여세요. 해당 주소의 호스트명과 일치하는 인증서 및 브라우저 신뢰 설정이 필요합니다. 연결 설정과 서비스 배포는 A1이 담당합니다.

확장 기능에 접속하면 지도 조회·비교·계산·후보 수락·리뷰 사본 저장을 사용할 수 있습니다. 운영 지도 적용은 별도 절차입니다.
