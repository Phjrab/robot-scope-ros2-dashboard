실제 주행 기록 방법

ROS 2 환경에서 기존 FAST-LIO가 실행 중일 때 아래 읽기 전용 기록기를 별도로 실행합니다. 종료는 Ctrl+C입니다.

python -m robot_dashboard.offline_slam.record --live --calibration-id 교정파일해시 --sensor-origin-body X Y Z --output run.json

이미 기록한 rosbag은 ROS 토픽으로 재생하지 않고 직접 읽습니다.

python -m robot_dashboard.offline_slam.record --bag BAG_DIRECTORY --calibration-id 교정파일해시 --sensor-origin-body X Y Z --output run.json

X Y Z에는 교정된 body 좌표계의 LiDAR 원점 위치(m)를 입력합니다. 2D 지도 광선의 시작점에 사용합니다.

입력은 같은 원본 시각의 /cloud_registered와 /Odometry입니다. 원시 LiDAR 전체 기록은 아니며, 로컬 좌표로 복원한 FAST-LIO 처리 점군을 저장합니다.

높이는 기록의 기준 좌표계 기준입니다. 경사·다층 환경의 2D 결과는 주행 지도로 별도 검증해야 합니다.
