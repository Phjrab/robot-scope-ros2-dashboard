# A3 작업 경계와 세션 인계

시작 공지는 Codex의 기존 A0·A1·A2 채팅에 전달 도구로 제출했고, 세 요청 모두 목적지 채팅 ID를 반환했다. 아래 범위는 동일한 내용을 보관한다.

| 담당 | 이번 변경과 맞닿는 범위 |
| --- | --- |
| A0 | 저장 지도·좌표·프리셋 데이터를 그대로 사용한다. 공용 지도 그리기 함수만 실험과 기존 화면에서 공유한다. |
| A1 | 공용 Navigation 작업, ROS seed/TF, 목표·STOP에 실험 분기를 추가한다. 현장 고정 버전, 장비, 배포 및 실제 이동의 소유자는 A1이다. |
| A2 | 일반 대시보드에 별도 실험 경로를 추가한다. 확장 메뉴와 리뷰 접근 권한은 A2 범위다. |

A1은 HTTPS 리스너와 리뷰 입력 연결을 위한 별도 작업 범위를 알려왔다. A3의 app.py 변경은 Navigation 요청 및 coordinator 연결에 한정한다. A1의 expansion 구성과 Uvicorn 실행부는 A1이 소유한다.

## 완료 공지에 사용할 내용

A3의 구현 SHA와 검증 결과는 `SOURCE_LOCK.json` 및 `ROUND1_RESULTS.md`에 있다. 사용 및 복귀 순서는 `HANDOFF.md`에 있다. A1은 현재 장비 소유권과 승인 범위를 확인한 후 이 SHA의 현장 배포와 시험을 맡는다. A3의 장비 검증 상태는 `DEVICE_NOT_RUN`이다.
