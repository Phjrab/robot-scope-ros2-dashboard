# Feature flags and rollback

All expansion flags default OFF. I0 adds an isolated /extensions product screen with separate multimap, scene, replay, usability and offline diagnostics capabilities. Native/active collision control is never enabled. No URL query or browser storage grants server authority.

The existing host has origin policy but no accepted expansion authentication provider: mutations and private reads remain BLOCKED_AUTH until an explicitly supplied owner callback is available. Synthetic loopback tests supply test-only callbacks.

Rollback disables flags, closes owned workers/subscriptions/renderers and restarts only a separately authorized local process. Do not restart any robot service. Saved immutable bundles stay review-only and are not installed as operational map families.
