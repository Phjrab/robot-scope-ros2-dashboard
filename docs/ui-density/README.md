# 대시보드 UI 정보량·일관성 정리

2026-10-23 · `codex/ui-dashboard-consistency` · 기준 `main`의 `67a77b6`.

기능 추가로 길어진 화면에서 현재 상태와 주요 조작을 먼저 찾을 수 있도록
배치와 안내를 정리했다. 기존 검정·초록/라이트 테마, IBM Plex 서체,
라우트, DOM ID와 입력값은 유지한다. 이전 UI 가독성 브랜치의 주요 개선은
이미 main에 통합되어 있으므로 오래된 브랜치를 다시 병합하지 않았다.

## 변경

- **지도 만들기:** 주 지도·매핑 조작·입력 상태 다음에 정지 Depth 캡처를
  배치한다. Depth는 공통 패널 헤더와 반응형 설정/저장 샘플 영역을 사용한다.
- **저장 지도 관측:** 상태·현재 수치·실패 사유는 계속 표시한다. 기준점,
  고급 옵션, 지도/수신 출처는 각각 펼쳐 볼 수 있다. 전역 관측의 긴 캡처
  메타데이터도 별도 상세로 옮기고 과거 관측이라는 한계는 상시 표시한다.
- **보정·미션·수집:** 짧은 핵심 안내를 먼저 제시하고 JSON 형식, 점 품질
  판정 기준, 미션 준비 순서, 파일 탐색 설명은 기본적으로 접는다.
- **공통 스타일:** SLAM/Depth의 글자 크기·버튼 높이·모서리·색상을 기존
  디자인 토큰에 맞춘다. 고정된 레거시 배경/보조 글자색을 테마 변수로 바꾼다.

## 기능 보존

Python, ROS, API, 관측 계산/판정, 제어 권한·세션 조건은 변경하지 않는다.
Depth 캡처의 기존 노드·리스너를 보존하고 DOM 배치와 표현만 변경한다.
화면 전환은 작업을 시작하거나 중지하지 않으며, 접기/펼치기는 네트워크
쓰기 요청을 발생시키지 않는다.

다음 안내는 접힌 도움말 밖에 남는다: 미검증 추정·운영 위치 미적용,
STALE/거절/실패 상태, 전역 관측의 과거 기록 한계, 보정의 상대 피치 한계,
촬영 전 세 가지 확인 조건, 미션/수집의 화면 이동 후 지속 여부,
소프트웨어 정지와 물리 E-stop의 차이 및 서비스 중지 경고.

## 검증

- Python unittest: 2,427개 실행, 성공(2개 건너뜀).
- JavaScript: 63개 파일, 개별 테스트 527개 성공.
- 전체 Playwright 회귀 검사: 174개 성공.
- 추가 브라우저 검사: 390/1440px × 다크/라이트, 키보드 펼치기,
  화면 이동 후 펼침 상태, 상태/안전 안내 표시, 지도/Depth 순서,
  반응형 배치, 44px 주요 버튼, 가로 넘침과 불필요한 쓰기 요청 검사.
- 전후 화면: 1440px 다크/라이트, 390px 다크, 768px 라이트에서
  지도·관측·수집·미션·보정 화면을 동일 합성 데이터로 비교했다.
  캡처에서 페이지 가로 넘침·JavaScript 예외가 없었다.

재실행:

```sh
python3 -m unittest discover -s tests -v
npm run test:unit
npm run test:e2e:ci
```

Python 검증은 의존성을 설치한 가상환경에서 실행했다. 개발 PC에 실제
`~/ws/go2_3d`가 있는 경우 테스트의 기본 디렉터리 권한 간섭을 피하도록
`ROBOT_SCOPE_WORKSPACE_ROOT`를 별도의 비어 있는 테스트 경로로 지정한다.
브라우저 검사는 로컬 합성 백엔드만 사용한다. 실장비 배포·서비스 재시작,
실제 센서 성능, Safari/iPad 하드웨어 검증은 이번 범위에 포함하지 않는다.
