# 위치 초안 조건부 정합: 독립 검토와 검증 상태

이 문서는 위치 초안을 이용해 전역 정합의 모호성을 줄이는 제안에 대한 사전 검토다. **최종 backend snapshot의 독립 검증은 아직 수행하지 않았다.** 기록된 개선과 테스트 결과는 구현 담당자의 보고이며, 실제 로봇에서의 정확도·정지·배포 준비를 뜻하지 않는다.

## 관측 결과의 해석

기록된 전역 관측은 여러 위치 가설을 구분하지 못해 navigation proposal이 `GLOBAL_AMBIGUOUS`로 거절됐다. 원본 관측은 override가 적용된 미검증 추정으로 표시되며, 최저 RMSE 후보를 실제 위치로 승격할 근거는 없다. 이전 관측은 현재 위치의 신선한 센서 증거가 아니다.

기존 범위 제한 정합은 단일 초기 가설의 참고 결과이며 `ambiguity_unresolved=true`를 유지한다. 이 결과를 전역적으로 유일한 navigation handoff로 바꾸는 경로는 기존 코드에서 확인하지 못했다. 사용자 위치 초안은 독립적 현장 단서와 명시된 불확실 범위에 바탕을 두어야 한다.

## 조건부 설계의 안전 계약

사용자가 지도 기준 본체 위치와 방향, 불확실 범위를 명시적으로 확인하고, 새 관측의 후보들을 같은 좌표계·기준 시점으로 변환해 기존 품질 정책을 적용한다. 남겨진 후보 집합에서 범위 안에 적격 후보가 정확히 하나여도 결과는 **사용자 초안과 해당 후보 집합에 조건부인 가설**이다. 전역 유일성, 실제 위치 정확도 또는 탐색의 완전성은 검증되지 않는다. 후보가 없거나 둘 이상이거나 후보·품질 정보를 신뢰할 수 없으면 거절한다.

원본 ambiguity와 품질 gate를 보존하고, 최저 RMSE 승격·임계값 완화·모호성 flag 조작을 하지 않는다. prior, 지도·교정·관측 세션·시각·후보 근거를 별도 versioned proof에 묶고 사용자의 확인, 정확한 관측 종료, 후속 초기 위치와의 일치 및 유효기간을 검증해야 한다. 위치 초안은 실제 초기 위치 전송이나 이동 명령이 아니다. 서버 확인 응답의 유실은 미적용으로 추정하지 않으며 readback과 복구 결과를 별개로 판정한다.

## 확인된 반례와 수리 보고

- 개발 중인 후보에서 사용자 prior가 있었는데도 전역 결과가 모호하지 않으면 prior 범위와 만료 검사를 거치지 않고 ready가 될 수 있는 반례가 기록됐다. 구현 측은 prior를 사용하는 경우에도 조건부 proof를 요구하도록 수리했다고 보고했다. 보존된 한 재검사에서 미준비 결과의 직접 원인은 테스트 runner 설정 누락이었으므로, 그 로그만으로 해당 수정의 유효성을 증명할 수 없다.
- 알 수 없는 후보 quality gate를 조용히 제외하고 다른 후보를 선택할 수 있는 반례가 기록됐다. 구현 측 합성 테스트 보고에는 알 수 없거나 잘못된 gate의 fail-closed 사례가 포함된다. 이 검토에서 최종 소스와 독립 재실행으로 수리 여부를 확인하지 않았다.
- prior가 받아들여진 시점에는 후보가 범위 안에 있지만, 이후 현재 pose가 사용자 범위를 벗어나도 기존의 더 넓은 handoff 거리 한도 내라면 confirm이 가능할 수 있음을 코드 읽기로 지적했다. 구현 측은 현재 pose가 사용자 범위와 기존 handoff 한도를 모두 만족하도록 수정했고 위치·방향 반례를 합성 테스트했다고 보고했다. 이 검토에서 최종 snapshot을 독립 검증하지 않았다.
- 구현 측의 pinned backend와 합성 점군 실험에서 중복 수렴 후보들이 각각 retained되어 여러 후보로 거절된 사례가 보고됐다. 이는 안전한 거절이지만 실사용성이 제한될 수 있다. 중복 기준을 완화하거나 후보를 임의 병합해서 해결됐다고 주장할 수 없다.

## 남은 검증

최종 고정 snapshot에서 no-prior 회귀, 품질·후보 누락과 unknown gate의 fail-closed, prior 시각과 현재 pose의 범위 검사, 3차원 좌표 변환과 yaw 경계, 조건부 proof 위변조·downgrade, stop·응답 유실·만료 및 후속 초기 위치 결속을 독립 검증해야 한다. 합성 검증은 센서 교정, 지도 정확성, 물리적 정지 또는 실제 환경에서의 위치 유일성을 입증하지 않는다. 별도의 현장 승인과 조건 확인이 있기 전 장비 실행·배포는 이 문서 범위가 아니다.
