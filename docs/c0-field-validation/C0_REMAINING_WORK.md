## 3. 현재 초안과 정지 센서 관측으로 초기값 취득·적용

상태: **새 흐름의 실장비 검증 미실행**.

- [ ] 현재 선택된 지도에 사용자가 현재 위치·방향의 X/Y/yaw 초안을 표시하고 정지 중인 로봇에 대한 가정임을 확인한다. 과거 초안을 자동으로 현재값으로 복원·전송하지 않는다. 불확실 반경·각도를 다시 필수 입력으로 요구하지 않는다.
- [ ] 승인된 비이동 범위와 기존 gate를 충족할 때 정지 센서 관측을 시작한다. 활성 bridge를 사용하는 경우 실제 명령 차단·서명 상태·소유권 조건도 확인한다.

- [ ] 초기 위치 제안을 계산해 후보 품질·그룹 구성원·모호성·현재 문맥을 확인한다. 서로 구별되는 적격 가설이 여러 개이거나 그룹/품질 검증에 실패하거나 검증 한도를 벗어나면 적용하지 않는다. 서버 기본 0.25m/0.20rad는 선택·적용 검증 한도이며 사용자 불확실성 측정이나 실제 정확도가 아니다.
- [ ] 유효한 지도 기준 본체 높이 z·roll·pitch를 사용자가 명시적으로 확인한 뒤 적용하고, 서버가 보관한 값과 출처를 다시 읽는다. 미확인 값을 0이나 과거 값으로 채우지 않는다.

완료 근거: 현재 map/revision·교정·session/source에 결속된 센서 증거, 제안 및 확인 식별자, 품질·거절 사유, 실제 적용값의 서버 readback. 센서 수신 성공과 초기값 적용 성공은 별도로 기록한다.

## 4. 관측 종료, Nav2, INITIAL POSE, 저장 지도 정합 연결

상태: **실제 연결 미검증**.

- [ ] 유효한 handoff와 현재 소유권·정지 조건을 확인한 뒤 Nav2를 시작하고 실제 노드·센서·TF 입력을 확인한다.
- [ ] 같은 지도·현재 세대의 초안을 명시적으로 재확인하고 INITIAL POSE를 전송해 실제 수락을 확인한다. 새로고침·초안 복원·Nav2 시작이 자동 재전송이나 출발을 유발하지 않아야 한다.

완료 근거: 관측 종료/복구, Nav2 실행, INITIAL POSE 수락, 정합 요청·상태를 각각 현재 세대에 연결한 기록. 이 단계에서는 goal이나 이동 명령을 보내지 않는다.

## 5. 지속 위치추정·Nav2/TF 반영과 표시 검증
