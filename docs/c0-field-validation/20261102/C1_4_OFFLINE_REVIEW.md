# 조건부 위치 가설 및 화면 변경: 독립 오프라인 검토

검토한 범위에서 추가로 확인된 차단 결함은 없다. 이 판정은 아래 고정 후보의 코드 읽기와 제한된 합성 확인에 한정된다. 통합 snapshot의 전체 검사 결과는 별도 기록하며, 실제 센서·로봇·지도 정확도·정지 상태·Nav2 동작·배포 가능성을 증명하지 않는다.

## 검토한 경계

- 조건부 위치 가설은 고정 backend의 기존 전체 SE(3) 중복 기준과 대표 순서를 검증하고, 원본 후보와 모호성 판정을 보존한다. 그룹의 모든 회원을 prior와 비교하며, 확인 시 같은 신선한 odometry 표본으로 각 회원의 현재 범위를 재검사한다. 원래 기준 안에서도 회원의 높이·기울기 차이가 남을 수 있으며, 하나의 retained 그룹은 전역 유일성이나 실제 정확도를 뜻하지 않는다.
- 그룹 proof UI는 원본 후보 수와 가설 수를 구분하고 회원·현재 진단, source/session·신선도 및 명시적 확인 조건을 검사한다. 모호성과 비모호 원본 판정의 표기는 실제 boolean을 반영하고, 두 경우 모두 사용자 초안 및 retained 후보에 대한 조건부 결과임을 표시한다.
- blur와 화면 숨김에서는 draft 처리 예외를 기존 disarm·녹화 정리와 별도 listener로 분리한다. 두 정상 handoff 대기 상태에서는 초안을 stale·전송 불가로 보존하고, 지도·교정·pair 세대 변경이나 다른 오류에서는 폐기한다. 실행 중 초안 사용을 위한 재확인과 실제 pose 전송은 별도다.
- private proof의 일관된 내부 값 변경에 관해 처음 제기한 P2는 철회했다. 확인 API에서 클라이언트의 proof 주입은 거부되고 readback은 복사본이다. 합성 반례는 신뢰된 내부 값을 직접 수정한 경우의 validator 한계를 보여주었으며, 실제 API에서 도달 가능한 결함을 입증하지 못했다.
